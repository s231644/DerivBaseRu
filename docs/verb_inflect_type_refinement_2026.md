# Уточнение автоматически определённых типов спряжения

Проверены 2261 многотипное автоматическое назначение и автоматические назначения
типа 11. Явные назначения из `data/verbs_roots.csv` не менялись.

Исходный генератор объединял все варианты pymorphy3, включая предсказания для
неизвестных слов. Такие предсказания сами по себе могут быть источником ошибки:
`апрувить → апрувью / апрувьёт`, `убредать → убредам / убредаст`,
`юродеть → юродену / юроденет`. Выбор самого вероятного предсказания
также не гарантирует правильной парадигмы.

Применён следующий порядок свидетельств:

1. Для словарных разборов pymorphy3 (`is_known`) запрашиваются формы **единственного
   числа** 1-го и 3-го лица. По ним существующий классификатор определяет типы.
   Разборы по аналогии (`is_known=False`) не служат доказательством выбора типа.
2. Учитываются явные номера типов в шаблонах спряжения локального Викисловаря,
   только если шаблоны распознаны во всех глагольных статьях леммы.
   Объединение типов разных статей сохраняется. Шаблон имеет приоритет над
   вариантами pymorphy3; при необходимости допускается новый базовый тип,
   отсутствовавший в исходном ошибочном объединении.
3. Для автоматического типа 11 проверяется основа `бить`, `вить`, `лить`,
   `пить`, `шить` с последовательностью известных приставок, в том числе
   несколькими. Одного окончания `-ить` недостаточно. Явный словарный шаблон
   11 имеет приоритет над этим ограничением. Для специального типа `дать`
   аналогично требуется сама основа `дать` с приставками.
4. Неизвестные слова без достаточных свидетельств не получают произвольно
   выбранный тип. Если ограничения удалили бы все варианты, исходный набор
   сохраняется для дальнейшей проверки.

Приставочная сегментация в пункте 3 — необходимое формальное ограничение,
а не подтверждение словообразовательной связи или семантики. Например,
`солить` формально допускает слияние `со + лить`, но его известные формы
pymorphy3 `солю / солит` исключают тип 11. Такие случаи покрыты тестом.

## Результат

| Показатель | До | После |
|---|---:|---:|
| Лемм всего | 46 895 | 46 895 |
| Один тип | 44 634 | 45 592 |
| Два типа | 2194 | 1266 |
| Три типа | 65 | 35 |
| Четыре типа | 2 | 2 |
| Многотипных автоматических лемм | 2261 | 1303 |

Изменены назначения у **960** лемм; у **958** неоднозначность устранена полностью.
У двух набор сокращён, но остаётся многотипным. Четыре типа у `обдержать`
и `оборжать` сохранены: pymorphy3 даёт только предсказания, а распознанного
словарного шаблона, позволяющего выбрать парадигму, нет.

Примеры:

| Лемма | Было | Стало | Основание |
|---|---|---|---|
| упережать | 14м, 14н, 5 | 1 | Явный шаблон `гл ru 1a` |
| юродеть | 1, 15 | 1 | Явный шаблон `гл ru 1a` |
| убредать | 1, дать | 1 | Явный шаблон `гл ru 1a` |
| апрувить | 11, 4 | 4 | Явный шаблон `гл ru 4a((3))` |
| амшить | 11, 4 | 4 | Ограничение основы типа 11 |

## Воспроизведение и файлы

```sh
.venv/bin/python scripts/refine_verb_inflect_types.py
.venv/bin/python scripts/rebuild_verb_suffixes.py \
  --include-rules rule836 rule840 --candidates-only \
  --out data/derived/verb_sfx.remaining.jsonl
.venv/bin/python scripts/verb_inflect_type_stats.py \
  --remaining data/derived/verb_sfx.remaining.jsonl
```

- `scripts/build_inflect_types.py` применяет тот же этап уточнения при полной
  сборке, после CSV-назначений.
- `docs/verb_inflect_type_refinement_2026.json` содержит все 960 изменений,
  свидетельства и контрольные суммы исходного/нового справочника.
- `data/derived/verb_inflect_type_refinement.jsonl` дополнительно описывает
  неразрешённые случаи; генерируемый файл исключён из Git.
- Текущая статистика и список оставшихся неоднозначностей обновлены в
  `docs/verb_inflect_type_stats_2026.json` и `docs/verb_inflect_multitype_2026.tsv`.

Принятые ранее суффиксальные и приставочные отношения автоматически не
пересматривались. TODO по исключению возвратных вариантов rule836/840 не применён.
При повторном запуске отдельного уточнения JSON-отчёт описывает изменения этого
запуска; уже уточнённый справочник повторно не меняет наборы типов.
