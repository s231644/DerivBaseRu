# Несколько автоматически определённых типов спряжения

Статистика текущего `data/verb_inflect_types.json` без повторного определения
типов и без изменения данных.

Генератор `scripts/build_inflect_types.py` объединяет типы из всех вариантов
`ZaliznyakGuesser(use_morph=True)`, затем заменяет назначения для лемм из
`data/verbs_roots.csv`. Поэтому 99 явно заданных CSV-назначений отделены от
автоматической группы. Это восстановление происхождения по алгоритму сборки:
сам итоговый JSON не хранит отдельной истории каждого назначения. Текущие
CSV-назначения совпадают с итоговым JSON, расхождений нет. Автоматические
предположения, впоследствии заменённые CSV, здесь не восстанавливались.

## Число типов у автоматически классифицированных глаголов

| Различных inflect_type | Глаголов |
|---|---:|
| 1 | 44 535 |
| 2 | 2194 |
| 3 | 65 |
| 4 | 2 |
| Всего | 46 796 |

**Несколько типов получили 2261 глагол — 4,8316% автоматически
классифицированных.**

Во всём справочнике 46 895 лемм, включая 99 CSV-назначений (все однотипные).
Доля многотипных от всего справочника — 4,8214%. Глаголы без назначенного типа
не входят в этот знаменатель. Считаются уникальные ключи-леммы, а не отношения
и не число морфологических разборов. Возвратные и невозвратные леммы, а также
написания с е/ё здесь не объединяются; повторения одинакового типа внутри
списка не учитываются.

## Наиболее частые точные сочетания типов

| Набор inflect_type | Глаголов |
|---|---:|
| 4, 11 | 822 |
| 1, 2 | 524 |
| 1, 6 | 304 |
| 1, дать | 104 |
| 1, 5 | 87 |
| 1, 15 | 83 |
| 4, 16 | 62 |
| 1, 14м | 47 |
| 1, 14м, 14н | 42 |

Всего 36 различных многотипных сочетаний. Четыре типа получили:

- `обдержать`: 5, 6, 14м, 14н;
- `оборжать`: 5, 6, 14м, 14н.

Многотипность сама по себе не означает ошибку: генератор объединяет варианты
разбора без выбора одного. В первую очередь стоит изучить массовые сочетания
4/11 и 1/2, а также назначения специального типа `дать` вместе с типом 1
(например, `валандать`, `владать`, `вырождать`). Это направления последующей
проверки, не новые решения о корректности типов.

## Основы в кандидатах rule836/840

В `verb_sfx.remaining.jsonl` 2754 различные родительские леммы.
Из них 2737 имеют автоматически определённые типы; **175 многотипные (6,3939%)**.

| Правило | Различных автоматических основ | Из них многотипных | Связей с многотипной автоматической основой |
|---|---:|---:|---:|
| rule836 | 2645 | 170 | 179 |
| rule840 | 199 | 10 | 11 |

В строках правил есть общие основы, поэтому 170 + 10 не равно 175.

## Файлы и воспроизведение

- `docs/verb_inflect_multitype_2026.tsv` — все 2261 автоматические многотипные
  леммы, типы и признак участия в оставшихся суффиксальных кандидатах.
- `docs/verb_inflect_type_stats_2026.json` — полные счётчики, 36 сочетаний
  с примерами и SHA-256 входных файлов.

```sh
.venv/bin/python scripts/verb_inflect_type_stats.py \
  --remaining data/derived/verb_sfx.remaining.jsonl
```

Если не передавать `--remaining`, собирается только общая статистика типов.
Исходные назначения типов, правила и кандидаты скрипт не изменяет.
