# Несколько автоматически определённых типов спряжения

Текущая статистика после [проверки парадигм](verb_inflect_type_refinement_2026.md)
и [проверки редких типов по основам и приставкам](verb_type_root_audit_2026.md).

99 явно заданных назначений из `verbs_roots.csv` отделены от автоматической
группы. Расхождений с итоговыми CSV-назначениями нет. В итоговом справочнике
не хранится история каждого назначения; группы восстановлены по сборщику.

**Многотипных: 1057 из 46796 (2.2587%).**

Всего в справочнике 46 895 лемм. Леммы без назначенного типа не входят
в знаменатель. Возвратные варианты и написания с е/ё считаются отдельными
ключами; повторения одинакового типа в списке не учитываются.

## Воспроизведение

```sh
.venv/bin/python scripts/verb_inflect_type_stats.py \
  --remaining data/derived/verb_sfx.remaining.jsonl
```

`docs/verb_inflect_multitype_2026.tsv` содержит все текущие многотипные леммы,
`docs/verb_inflect_type_stats_2026.json` — счётчики, сочетания, примеры и SHA-256.
Без `--remaining` собирается только общая статистика. Скрипт статистики
исходные назначения и кандидаты не меняет.
