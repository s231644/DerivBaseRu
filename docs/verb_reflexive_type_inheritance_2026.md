# Перенос типов на оставшиеся возвратные глаголы

По указанию пользователя для многотипных возвратных лемм типы скопированы
из соответствующей леммы без `-ся/-сь`. Рассмотрено 322 леммы:

- у 259 назначения изменены;
- у 24 типы уже совпадали;
- для 39 невозвратная основа отсутствует в справочнике — типы сохранены.

У 258 глаголов остался один тип. Всего многотипных лемм: 401 → 143.
Невозвратные леммы не менялись. Общий многотипный набор основы копируется
целиком; метод не выбирает одну из её реальных парадигм.

Полный перечень: `docs/verb_reflexive_type_inheritance_2026.json`.
Этап включён последним в `scripts/build_inflect_types.py`.

```sh
.venv/bin/python scripts/inherit_reflexive_verb_types.py
.venv/bin/python scripts/verb_inflect_type_stats.py
```

Генерация кандидатов не запускалась.
