# Генерация оставшихся глагольных суффиксов

Повторно сгенерированы оставшиеся без проверки правила из
`derivbase_ru/rules/rus/verb/simple/verb=verb+sfx.json`: rule836 (-ну₂-)
и rule840 (-ану-). Остальные правила файла уже прошли генерацию и последующий
отбор; их результаты не перезаписывались. Это генерация кандидатов,
не семантическое принятие отношений.

| Правило | Сырых кандидатов | Со словарным свидетельством | Только токен Даля |
|---|---:|---:|---:|
| rule836 | 75 914 | 2820 | 666 |
| rule840 | 43 501 | 208 | 11 |
| Всего | 119 415 | 3028 | 677 |

Обработано 47 460 исходных глаголов; у 46 884 есть тип спряжения.
Источником типов стал актуальный `data/verbs_registry.jsonl.gz`, включающий
LLM-проверку невозвратных лемм и перенос типов возвратным. Контрольная сумма
реестра и полный манифест запуска сохранены в
`docs/verb_suffix_remaining_generation_2026.json`.

Результаты в `data/derived/` (генерируемые файлы исключены из Git):

- `verb_sfx.remaining.jsonl` — 3028 кандидата с `review_status: pending`;
- `verb_sfx.remaining.doubtful.jsonl` — 677 кандидат только по токену Даля,
  подмножество предыдущего файла;
- `verb_sfx.remaining.raw.jsonl.gz` — все 119 415 сырых порождений;
- `verb_sfx.remaining.manifest.json` — статистика и SHA-256 входов/выходов.

```sh
.venv/bin/python scripts/rebuild_verb_suffixes.py \
  --include-rules rule836 rule840 --candidates-only \
  --out data/derived/verb_sfx.remaining.jsonl
```

Выборочная генерация требует отдельного пути вывода и `--candidates-only`,
чтобы не заменить основной набор частичным и не запускать общий семантический
отбор над неполными данными. Неверный идентификатор правила останавливает запуск
до чтения словарей. Запуск без новых параметров сохраняет прежнее поведение.
