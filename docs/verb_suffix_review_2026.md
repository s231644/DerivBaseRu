# Первый строгий отбор глагольных суффиксальных связей

Первый проход 24 октября 2026 года. Текущий отбор дополнен [проверкой по типам](verb_suffix_type_review_2026.md); приведённые ниже числа относятся к первому проходу. Единица подсчёта — связь, а не уникальное слово.

rule930 принимается как регулярное по указанию пользователя. Дополнительная семантическая проверка не выполнялась, включая 334 связи, ранее помеченные как doubtful.

rule846–850: явно заданные непродуктивные пары приняты по спискам `rare` правил. Дополнительно проверены порождения -лечь → -ложить. `слечь → сложить` отклонена: «заболеть» не является исходным значением для каузатива «сложить». `отлечь → отложить` изолирована: у отлечь есть значения исчезновения боли/тревоги, каузативная связь не подтверждена. Остальные порождения сохранены в соответствующих пространственных/каузативных значениях.

`жалеть → жалить` (rule850) сохранена: в локальном словаре Даля есть отдельная статья «ЖАЛИТЬ на что, по чем, стар.» со значением жалеть/скорбеть. Современное «ранить жалом» — другое значение; автоматическое удаление по нему было бы ошибкой.

rule842: принимаются явно заданные исключения и пары, для которых хотя бы одна русская глагольная статья локального Викисловаря прямо указывает второй глагол в поле `соотв`. Ударения и е/ё нормализуются, из wiki-ссылок извлекается целевая лемма. Синонимы, родственные слова и простое наличие обеих лемм доказательством связи не служат. Это словарное подтверждение связи на уровне лемм, без разметки отдельных значений и омонимов.

Шесть вручную проверенных ложных пар rule842 имеют приоритет над автоматическим подтверждением: выморить → вымарать, подавить → подавать, кокнуть → качать, подлетнуть → подлечивать, отродить → отражать, смалить → смалывать. Причины сохранены в `data/reviews/verb_sfx_policy.json`.

Неподтверждённые пары rule842 вынесены в очередь, а не объявлены ошибочными. Там остаются в том числе правильные редкие и многократные образования, для которых `соотв` отсутствует. rule836 и rule840 пока не проверялись; их прежние кандидаты сохранены.

## Повторный запуск (включает последующий отбор по типам)

```sh
.venv/bin/python scripts/review_verb_suffixes.py
.venv/bin/python scripts/prepare_graph_viewer.py
```

Генератор `scripts/rebuild_verb_suffixes.py` автоматически запускает этот отбор после генерации. Повторная проверка читает неизменённый `verb_sfx.raw.jsonl.gz`, выбирает только лексически засвидетельствованные кандидаты и воспроизводит разбиение, не теряя ранее изолированные связи.

Результаты первого прохода в `data/derived/` (текущие числа см. в отчёте по типам):

- `verb_sfx.jsonl`: 28 798 связей (включая 3 033 ещё не проверенные связи rule836/840).
- `verb_sfx.semantic_pending.jsonl`: 12 135 связей, исключённых из основной визуализации до проверки.
- `verb_sfx.semantic_rejected.jsonl`: 7 отклонённых связей с причинами.
- `verb_sfx.doubtful.jsonl`: 681 оставшийся кандидат rule836/840 с подтверждением только токеном Даля.
- `verb_sfx.semantic_review.json`: счётчики и SHA-256 входов/выходов. Генерационный `manifest.json` описывает состояние до семантического отбора.

Исходные сырые кандидаты и JSON-правила не изменялись. Производные JSONL и sidecar-файлы исключены из Git правилами проекта; код, политика решений и этот отчёт версионируются.
