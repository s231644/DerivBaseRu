# Проверка оставшихся основ типов 7 и выше

24 октября 2026 года. Проверены все оставшиеся спорные связи, у родителя которых есть хотя бы один числовой тип ≥7, включая смешанные типы. Дополнительно проверены оставшиеся связи с особой основой дать (сочетание 1, дать). Ранее принятые пары заново поголовно не пересматривались; rule930 не требует проверки по указанию пользователя.

Всего явно рассмотрены **374 пары / 297 исходных глаголов**: 341 пара с числовым типом ≥7 и 33 с основой дать. **236 приняты, 109 отклонены, 29 оставлены спорными**. Для каждой пары сохранены решение и причина в `data/reviews/verb_sfx_type7plus.jsonl`; у 73 принятых возвратных пар записана также подтверждённая безвозвратная опора.

Числа относятся к парам в исходной очереди этого прохода. Отдельно исправлено одно прежнее ошибочное отклонение типа 4: отродить → отражать, см. ниже.

## Принцип проверки

Сопоставлялись значения обеих лемм в локальных Викисловаре и Дале, в том числе разные омонимы. Корень, приставка и возвратность проверялись вместе. Подтверждённая активная пара служит дополнительной опорой для возвратной/страдательной формы; её наличие не использовалось для принятия явно другого лексического значения.

Группа 11, 4 велика из-за неоднозначности определения исходного типа. Например, для пары припить → приплывать нельзя выбирать операции типа 11 только потому, что этот тип присутствует рядом с 4. В выгрузке оба типа сохраняются; проверка лексическая, а не произвольный выбор одного тега.

Приняты, в частности:

- `обдержаться → обдерживаться`, `одержаться → одерживаться`: у Даля соответствующие статьи прямо предусматривают возвратные и страдательные формы.
- `втопить → втоплять`: у Даля плотницкое значение втопить доску в брус; современное ускориться здесь не единственное значение.
- `покопить → покапливать`: у Даля прямо сказано о накоплении денег, не о падении капель.
- `умолиться → умаливаться`: отдельная статья УМАЛИВАТЬ у Даля означает упрашивать/умолять и допускает -ся; не только уменьшаться.
- `владать → владывать`, `ложить → лагать`: исторические варианты владения и укладывания; современные омонимы не отменяют этих значений.
- `вычесть → вычитывать`, `причесть → причитывать`, `счесть → считывать`: Даль фиксирует старые соответствия чтения/счёта. Не следует оценивать их исключительно по современному наиболее частому значению.

`скипеть → скипать` подтверждено как диалектная пара кипения: [А. К. Ленивов, «Донской казачий словарь-лексикон», 1971, с. 138](https://vtoraya-literatura.com/pdf/lenivov_donskoj_kazachy_slovar-lexicon_1971_text.pdf). Это не современный англицизм skip.

Отклонены, в частности:

- `припить → приплывать`, `упить → уплывать`, `распиться → расплываться`: смешение пить и плыть.
- `свежить → сведывать`, `позабить → позабывать`, `придаться → приживаться`: ложные обратные чередования, дающие другой корень.
- `пряжить → прядывать`: жарка в масле подменена прыжками.
- `кровить → кровать`: в подтверждающих контекстах цели присутствует существительное, а не производный глагол.
- `ясти → ясать`: есть подменено мастерить/делать; это разные словарные гнёзда Даля.
- `расчесть → расчитывать`, `расчесться → расчитываться`: расчёт/расплата подменены чтением, описанным у Даля под формой с одним с.
- `укладать → уклаживать`: укладывание подменено навариванием сталью (укладить у Даля).

Для `расти → растать` не найдено свободного глагола со значением роста: контексты на(воз)растать не подтверждают самостоятельную лемму. Напротив, значение таяния у растать засвидетельствовано в [словаре Долопчева, 1886, статья «Растать»](https://ru.wikisource.org/wiki/Страница:Опыт_словаря_неправильностей_в_русской_разговорной_речи_(Долопчев,_1886).pdf/132). Поэтому конкретный сгенерированный разбор отклонён.

## Исправление прежней ошибки

Ранее отродить → отражать было отклонено из-за современного значения отражать свет/нападение. У Даля в статье ОТРОЖАТЬ прямо перечислены отрожать (отражать), отрождать, отродить в значении рождения детей/потомства. Прежнее отклонение снято, пара принята с явной оговоркой о значении. Решение хранится в `data/reviews/verb_sfx_policy.json`.

Для отлечь → отложить также учтено старое значение: у Даля ОТЛЕГАТЬ отлечь означает быть отлагаемым, оседать (о гуще). Каузатив rule846 принят именно для этого значения; значение исчезновения боли не является основанием для принятия.

## Что осталось спорным

29 пар явно рассмотрены, но не переведены в основной файл. Это не пропущенная проверка: для каждой в policy записано, какого свидетельства не хватает. Одни формы имеют пустые определения, другие могут быть параллельными суффиксальными вариантами вместо отношения rule842; несколько исторических значений не подтверждены.

| Родитель | Производное | Почему решение открыто |
|---|---|---|
| вживиться | вживаться | У вживиться нет определения в доступной статье. Вживаться относится к освоению/привыканию; требуется отличить это от вживления/имплантации. |
| вкрепить | вкрепать | Вкрепать/вкрёпать у Даля — всовывать/вколачивать и уже может быть совершенным. Вкрепить — закрепить; не доказано, что это имперфектив. |
| вкрепить | вкрепывать | Вкрепывать у Даля связано с вкрёпать (вколачивать). Для вкрепить (закрепить) нужно подтверждение того же значения. |
| дострелить | дострелять | Обе современные формы совершенного вида, значения добить выстрелом и закончить стрельбу различаются. Общая статья Даля не доказывает именно имперфективацию. |
| забашлить | забашлять | Значение заплатить совпадает, но обе формы совершенного вида: это суффиксальные варианты, а не подтверждённое отношение rule842. |
| измолить | измалять | Измалять в словарном контексте требует отличения от изменять/умалять; прямого молитвенного соответствия измолить не найдено. |
| новить | новать | Новать найдено в тексте как отсекаемый фрагмент переэкзаменовать/старновать. Самостоятельное глагольное значение обновлять не подтверждено. |
| новить | новлять | Новлять встречается в сокращённых/разорванных формах перестановлять/подстановлять. Нет самостоятельной глагольной статьи с нужным значением. |
| обдолбить | обдолбать | Оба слова засвидетельствованы, в общем наркотическом значении оба совершенного вида. Для rule842 нужен имперфективный/многократный статус цели, а не одно совпадение значений. |

| оставиться | оставаться | Оставаться соотнесено с остаться, а оставиться обычно страдательное от оставить. Старое совпадающее значение источника требуется подтвердить отдельно. |

| увалиться | уваляться | Увалиться у Даля — отклониться/уйти, уваляться — уплотниться валянием или испачкаться. Нужно прямое значение валяния у увалиться для принятия пары. |

## Результаты и воспроизведение

После этого прохода основной `verb_sfx.jsonl` содержит **32 187** связей, `semantic_pending` — **8 541**, `semantic_rejected` — **212**. Среди оставшихся pending с типами ≥7/особыми основами все 29 имеют метод `explicit_type7plus_review`; остальные pending относятся к более ранним типам и этим проходом не менялись.

Исходные 374 пары сохранены локально в `data/derived/verb_sfx.semantic_pending.before_type7_review.jsonl`. Итоговая очередь заново сгруппирована в `verb_sfx.semantic_pending.jsonl`, индекс и отдельные файлы групп обновлены. Новый файл решений применяется раньше прежних pending и малых групп, поэтому повторная генерация не отменяет этот проход.

```sh
.venv/bin/python scripts/review_verb_suffixes.py
.venv/bin/python scripts/prepare_graph_viewer.py
.venv/bin/python -m unittest discover -s tests -p 'test_verb_suffix*review.py'
```
