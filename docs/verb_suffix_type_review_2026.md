## Явная проверка малых групп

Критерий малого размера: не более 20 пар на точное сочетание исходных типов до этого прохода. Полностью рассмотрены 50 групп / 289 пар: **238 приняты, 41 отклонена, 10 оставлены спорными**. Для каждой пары в `data/reviews/verb_sfx_rare_types.jsonl` сохранены типы, исходный размер группы, решение и причина. Размер группы — способ организовать проверку, не признак правильности.

Исторические значения сверялись с локальными `data/dahl/dahl.jsonl.gz` и `data/wiktionary/parsed_ru.jsonl.gz`. В частности:

- `взяться → взиматься` принято: у Даля есть страдательное значение о собираемых податях.
- `посесть → поседать` принято по прямому сопоставлению у Даля; не путать с седеть.
- `навидеться → навидаться` принято в значении свидеться/повидаться у Даля.
- `попереть → попирать` принято в значении напирать/нажимать, явно описанном у Даля.
- `забидеть → забиждать` и `толочь → толакивать` подтверждаются старыми словарными формами.
- `хитить → хитать` отклонено: у Даля хитать означает качать/колебать.
- `подмяться → подмываться`, `нажаться → наживаться`, `припеть → приплывать` отклонены из-за смешения корней.

## Сильные признаки для крупных групп

| Признак | Дополнительно принято из исходной очереди |
|---|---:|
| Тип 2: точное -овать/-евать → -овывать/-евывать | 392 |
| Сохранённая основа при -ать → -ивать/-ывать, -ить → -ивать | 2298 |
| Вставка -ва- для специальных классов | 44 |
| Узкая явно ограниченная семья корня | 180 |
| Явные решения малых групп | 238 |

**Тип 2:** приняты все 392 пары: 327 с единственным типом 2 и 65 с сочетанием 1, 2. Сравнивается вся пара, а не одно окончание цели: `арендовать → арендовывать`, `межевать → межевывать`, `танцевать → танцовывать`. Учтено цев/цов; приставочная часть и возвратность обязаны совпадать. Пары с чужой основой или добавленным -ся не принимаются.

**Сохранение основы:** свободные обратные чередования не допускаются. -ить → -ывать не обобщается: `обрить → обрывать`, `выкалить → выкалывать`, `поубить → поубывать` ошибочны. У типа 14 корневая я/а может ошибочно исчезать: такие типы и неоднозначные сочетания с ними исключены из общего признака. Отдельно исключены короткие основы вроде гнать: `догнать → догнивать` не принимается.

**Вставка -ва-:** допускается для классов 11, 12*, 15, 16, быть, дать при полном сохранении остальной основы. На тип 1 с -еть признак не распространяется: `свежеть → свежевать`, `помалеть → помалевать` меняют значение.

**Семьи:** применяются только перечисленные в `scripts/verb_suffix_type_review.py` соответствия при неизменной приставочной части и возвратности, например `скрести → скребывать`, `молоть → малывать`, `жечь → жигать`, `нять → нимать`, `толочь → толакивать`. Это не общее разрешение на чередования.

**Отрицательные признаки:** `вести → ведать/ведывать` смешивает разные корни; непереходное `сесть → саживать` даёт каузатив вместо имперфектива; `бечь → бекать` и `мочься → мокаться/макиваться` смешивают разные значения. Эти узкие случаи отклоняются. Отсутствие сильного положительного признака само по себе не ведёт к отклонению.

Автоматическое принятие — решение по сильной формальной сигнатуре для уже лексически засвидетельствованных кандидатов. Полноценное разрешение омонимии и значений оно не заменяет. Редкие явные решения и сохранённые исключения имеют приоритет.

## Повторный запуск

```sh
.venv/bin/python scripts/review_verb_suffixes.py
.venv/bin/python scripts/prepare_graph_viewer.py
.venv/bin/python -m unittest discover -s tests -p 'test_verb_suffix*review.py'
```

Отбор встроен в генератор суффиксов. Повторный запуск читает исходный raw, применяет версионируемые решения и сигнатуры, заново группирует оставшиеся pending и формирует отчёт с SHA-256. Производные данные остаются под действующими исключениями Git; политика и код проверки версионируются.
