# Редкие типы: проверка основы и приставок

Для редких типов проверяется необходимое условие: инфинитив должен состоять из
основы соответствующего типа в `data/verbs_roots.csv` и нуля или нескольких
приставок. Проверка не использует сгенерированные приставочные отношения,
поскольку в них самих есть ложные пары.

Реестр основ собирается по всем строкам CSV, включая `real=0`: это намеренно
заданные связанные основы. Омонимы объединяются **по типам**, поэтому `жать`
допускается и для 14м, и для 14н, хотя прежний сборщик явных назначений использует
последнюю CSV-строку. Здесь сами явные назначения не меняются.

Алгоритм динамическим программированием разбирает остаток перед основой на
полный список приставок и их алломорфов. Учитываются:

- возвратные окончания `-ся/-сь` (только при анализе, кандидаты не удаляются);
- несколько приставок: `недо-пере-лить`;
- разделительный ъ: `изъ-ять`, `подъ-ехать`;
- варианты `идти → -йти` и `ять → -нять`: `разо-йти`, `под-за-нять`.

Если редкий тип не допускает такого разбора, он исключается из набора вариантов,
**пока в наборе остаётся хотя бы один другой тип**. Если исключены были бы все
варианты, слово остаётся в отчёте неразрешённым: новый тип не придумывается.
Продуктивные типы 1–6 эта проверка не ограничивает.

## Результат

Изменены назначения у **265 глаголов**. У **246** остался один тип, у **19**
набор сокращён, но всё ещё содержит несколько типов.
Число многотипных назначений: **1303 → 1057**.

| Пример | Было | Стало |
|---|---|---|
| барыжить | 16, 4 | 4 |
| бурдеть | 1, 15 | 1 |
| воскипеть | 12петь, 5 | 5 |
| ввестись | 7д, 7с | 7д |
| взгнести | 7с, 7т | 7т |
| пожать | 14м, 14н | 14м, 14н |

У `пожать` оба типа имеют допустимую основу `жать`, поэтому этим методом их
не разделить. Формальное совпадение с приставкой необходимо, но не достаточно:
например, `со + лить` само по себе не доказывает тип 11 для `солить`.
Словарные формы проверяются предыдущим этапом уточнения. Для предложенных
изменений не найдено конфликтов с распознанными номерами шаблонов Викисловаря.

Ещё **305 записей** оставлены для проверки: либо все текущие варианты не проходят
ограничение, либо для подтипа нет отдельного реестра основ. В частности, CSV
не задаёт отдельных списков для `10ел`, `14ним`, `14им`, `14ьм`, `14ым`.
Эти подтипы не приравниваются автоматически к соседним и не отбрасываются.

## Воспроизведение

```sh
# Только отчёт, без изменения справочника:
.venv/bin/python scripts/audit_verb_type_roots.py

# Применить сужение наборов:
.venv/bin/python scripts/audit_verb_type_roots.py --apply
```

`docs/verb_type_root_audit_2026.json` хранит рассмотренные случаи, исходные и
итоговые типы, найденные разложения, неизвестные подтипы и контрольные суммы.
Повторный запуск отчёта описывает текущее состояние и заменяет предыдущий отчёт.

Этап включён в `scripts/build_inflect_types.py` после уточнения по словарным
парадигмам. Кандидаты rule836/840 пересобраны с обновлёнными типами; фильтрация
рефлексивов по TODO не применяется. В оставшемся наборе 3032 связи: 2823
по rule836 и 209 по rule840. Перестала порождаться `оплестись → оплеснуться`: у
`оплестись` исключён тип 7с, сохраняется тип 7т. Ранее принятые отношения не пересматривались.
